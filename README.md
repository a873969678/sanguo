## 素材放置与命名

- 原剧截图和用户提供的参考资料放在 `输入/`。
- 当集生成的人物图、武器图等放在 `剧集/EPxxx/制作成果/images/` 的对应分类中。
- 被确定为全剧复用的角色与道具素材，保存一份到 `公共素材/`；单集引用公共文件，不无故复制一套。
- 草稿用 `名称_用途_v001.png`、`名称_用途_v002.png` 递增，例如 `关咪_猫脸卡通角色板_v001.png`、`刘咪双枪_卡通道具板_v001.png`。
- 定稿用明确的 `定稿` 后缀，改版保留旧版本；文件内容未定稿时，不只改名为定稿。
- 镜头素材沿用分镜ID，例如 `SHOT-EP001-001_v001.png` 和 `SHOT-EP001-001_v001.mp4`。
- 新的一集沿用 `EP002`、`EP003` 等编号，创建同样的素材分类目录，并引用全剧公共素材。
