# 三国群萌传

以1994版电视剧《三国演义》为剧情依据的抖音猫咪短剧。刘咪、关咪、张咪采用真实猫脸、二维卡通身体与服装、卡通枪械，沿用已确认的小巧可爱风格母版和公共Qwen声线。

## 当前状态

2026-10-09用户确认第一集《关张初遇》已发布。本地当前交付为v006：123.92秒、1080×1920、24fps，12句对白、25条字幕、5个首次出场名字卡及4段配乐。未提供抖音链接，未独立核对线上文件。

成片、封面、发布文案、实际剪辑及清理记录统一从[EP001工作区](剧集/EP001/README.md)进入。发布后已清理废弃素材与临时脚本，旧路径只用于追溯，不重新作为生产输入。

第二集《桃园结义》最终v011已获用户确认：122.792秒、1440×2560、24fps，包含新民乐、舞蹈口令与水印局部修复。已清理旧成片、预览和一次性脚本。[打开第二集工作区](剧集/EP002/README.md)。
