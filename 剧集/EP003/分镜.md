## SHOT-EP003-001 · 山河推进至城外军阵（连续长镜前段）

- 来源：EP003-SC001、EP003-SC002、EP003-SC003；局势介绍、巨轮、董咪、骑大狼狗的吕咪、步兵冲锋与噜噜发射。
- 时长：25秒；全片0—25秒；对应生成分段SEG-EP003-001。
- 职责：在同一地理内从天下局势推进到董咪军的实际压迫。
- 景别／机位：高空大全景 → 船体远景 → 甲板中近景 → 岸边军阵中景；通过摄影机接近改变景别，不连续跳焦假装换场。
- 运镜：沿河下降，掠船舷进入甲板；从董咪身侧离开，沿同岸弧线移到陆军外侧。董咪与吕咪的亮相区减速；吕咪先给骑乘组合全貌，再收至可辨猫脸的中景，不为狗另加切镜或加时。其余过路区适度提速。
- 起点 → 主要动作 → 终点：山河城池与小比例巨轮形成同一空间 → 连续揭示董咪和骑大狼狗的吕咪军，前排步兵短射、噜噜一次发射 → 弹体已抵城防、墙面出现小范围尘团，噜噜双手仍稳扶原筒，镜头准备升高。
- 连续性：董咪不下船；吕咪始终骑在大狼狗背部稳定支撑位置，狗四足着地朝城池，不变马、不咬兵、不额外冲锋；两者留在军阵中央。船、河、岸、城关系不互换。以攻军阵地至闭合城门为主轴，镜头在河岸一侧绕行，攻方朝远处城池前进。
- 声音：仅开场第一段旁白，统一后期加入；片内不生成对白、犬吠与动作音。配乐跨25秒交界保持连续。
- 文字：董咪、吕咪名卡只按首次可辨入画叠加一次；生成画面没有非画内字幕。

## SHOT-EP003-002 · 城外火力推进至城内萌主（连续长镜后段）

- 来源：EP003-SC003、EP003-SC004、EP003-SC005；承接火箭筒发射后的状态、空中扫射、两层守军、穿城、袁本喵。
- 时长：20秒；全片25—45秒；对应生成分段SEG-EP003-002。
- 职责：把城外攻击压力带到城内联军统领，完成对抗双方的介绍。
- 景别／机位：陆地中景 → 抬升到驾驶窗可辨距离 → 城前和城墙中远景 → 城内主街 → 袁本喵中近景。
- 运镜：从前段同位置开始升高，城墙尘团自然散开，不重演发射；升到直升机侧前方，驾驶窗停留约2秒，再带出扫射方向；拉开看城前守兵，越过城上守兵与城垛，沿街减速至袁本喵。全程可解释为无实体摄影机连续飞行，不模拟敌军视点。
- 起点 → 主要动作 → 终点：噜噜已完成发射、墙面尘团仍在 → 升高展示牛来驾驶与直升机扫射，掠过城前与城上守兵，穿城抵达院前 → 袁本喵脸部和铠甲可辨、身形稳定，名卡读完，战事结果仍未定。
- 连续性：火箭只在第一段发射一次，续接不重复发射或步兵短射；牛来在舱内驾驶，扫射来自机载武器。攻方始终城外；城门闭合，镜头从城墙上方进入，外墙尘团不导致内城突然大火或城防坍塌。
- 声音：仅结尾第二段旁白与连续电视剧配乐，绝无枪炮、旋翼、脚步、犬吠或喊杀。25—38秒只有配乐。
- 文字：袁本喵首次可辨后后期叠加“袁本喵／猪咪萌主”。噜噜、牛来在本集充当兵种，不增添额外个人名卡；如需独立介绍，另由用户决定，不能挤占结尾。
